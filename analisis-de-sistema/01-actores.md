# Actores del sistema

## Marketplace de productos para mascotas

Los actores representan a las personas, organizaciones o sistemas externos que interactúan con el Marketplace.

| ID | Actor | Tipo | ¿Qué necesita realizar? |
|---|---|---|---|
| ACT01 | Cliente | Usuario | Buscar productos, consultar información, agregar productos al carrito, realizar pedidos, efectuar el pago y consultar sus pedidos. |
| ACT02 | Seller | Usuario | Ofrecer productos, registrar productos, actualizar productos, consultar sus productos y gestionar la información relacionada con sus ventas. |
| ACT03 | Administrador | Usuario | Administrar la plataforma. |
| ACT04 | Pasarela de pago | Sistema externo | Procesar pagos. |
| ACT05 | Servicio de envío | Sistema externo | Gestionar información de entrega. |
| ACT06 | Servicio de Facturación | Sistema externo | Generar comprobantes de pago. |
| ACT07 | ERP | Sistema externo | Proporcionar información de productos y stock. |
